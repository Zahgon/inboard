Not covered

Read before scoring candidates with this oracle

The oracle exercises write paths for routing and authorization only, not mutation semantics — a candidate could pass all 17 tests with a broken update handler. Write paths were verified for this migration by the separate differential run above, but that is not part of the scored oracle.

  • /auth/refresh and /auth/logout — refresh claim is a database-stored UUID a minted token cannot satisfy; covered by the Go unit tests instead.
  • TLS, the jwt cookie token source, and SMTP beyond the stdout fallback — untested, not assumed working.
  • Content-Type is deliberately not asserted in the oracle; doing so would fail a correct migration on charset case alone.
